📐 线段动点综合 · 整体思想

题目：

(1) 点C是线段AB上一定点，点D从点A，点E从点B同时出发分别沿直线AB向左，向右匀速运动，若点E的运动速度是点D运动速度的3倍，且整个运动过程中始终满足 CE = 3 CD，求 AC : AB 的值；

(2) 如果在(1)的条件下，若点M从点B出发沿直线AB向左运动，运动速度是点D速度的3倍。在点D,M运动过程中，P，Q分别是AM, CM的中点，若运动到某一时刻，恰好 CM = 4 PQ，求此时 AD : AB 的值。

初始位置 A —— C —— B （从左到右）

🔍 第一问 · 不变量 CE = 3CD 的由来

CD = 1.50, CE = 4.50, 3CD = 4.50 ✅

📘 整体思想 · 抵消

设 D 速度为 v，时间 t，则：

AD = vt，BE = 3vt
CD = AC + AD = AC + vt
CE = CB + BE = CB + 3vt

由 CE = 3 CD 得：

CB + 3vt = 3(AC + vt) = 3AC + 3vt

两边同时减去 3vt，动态项完美抵消：

CB = 3AC → AB = 4AC → AC:AB = 1:4

💡 关键：速度倍数(3倍)使 vt 项相同，等式相减后只剩下固定长度关系，与运动速度和时间无关。

🧩 第二问 · 两种解法详解

t = 0.80, AD = 0.80, BM = 2.40, PQ = 0.50 (恒定)

📈 坐标法 · 动态抵消 (使用 a, v)

由第一问知 AC:AB = 1:4，设 AC = a，则 AB = 4a，BC = 3a。

建立数轴，令 A=0，C=a，B=4a。

点D速度 v，时间 t → AD = vt，D 坐标 = −vt。

点M速度 3v，从B向左 → BM = 3vt，M 坐标 = 4a − 3vt。

P 是 AM 中点：P = (0 + M)/2 = 2a − 1.5vt

Q 是 CM 中点：Q = (a + M)/2 = 2.5a − 1.5vt

PQ = |P − Q| = |(2a−1.5vt) − (2.5a−1.5vt)| = 0.5a

−1.5vt 完全抵消，PQ 恒等于 AC/2 = a/2，与 M 位置无关。

又 CM = |M − C| = |4a−3vt − a| = 3|a−vt|。

令 AD = vt = x，则 CM = 3|a−x|。

条件 CM = 4PQ = 4·(a/2) = 2a：

3|a−x| = 2a → |a−x| = 2a/3 → x = a/3 或 5a/3

所以 AD:AB = x : 4a = 1:12 或 5:12。

✅ 无需分类，绝对值自动处理位置。

t = 0.50, M 在 C 右侧, CM = 1.50

📐 分类讨论 · 位置变化 (使用 a, v)

同理 AC=a，BC=3a。令 AD=vt=x，则 BM=3x。

临界点： M 到达 C 时 BM = BC = 3a → 3x = 3a → x = a。

情况 1： x < a （M在C右侧，BM < BC）
CM = BC − BM = 3a − 3x
PQ = a/2 (恒等)
3a − 3x = 2a → x = a/3 → AD:AB = 1:12
情况 2： x > a （M在C左侧，BM > BC）
CM = BM − BC = 3x − 3a
PQ = a/2 (恒等)
3x − 3a = 2a → x = 5a/3 → AD:AB = 5:12

💡 注意： x=5a/3 时 M 已越过 A（坐标 −a），但题目只说“沿直线”，故两个解均成立。

🧠 “整体思想”终极总结

第一问 · 不变量

CE = 3CD 中，两项都含有 3vt，等式相减后完全抵消，得到固定的 CB = 3AC。

速度倍数(3)使时间项相同，整体抵消。

第二问 · 动态抵消

P、Q 均为中点，坐标差中 M 的坐标完全抵消：

PQ = |(A+M)/2 − (C+M)/2| = |A−C|/2 = a/2

与 M 的位置无关，PQ 恒等于 AC/2。

设 AD=vt=x，则 CM=3|a−vt|=3|a−x|，代入得两个解。

整体思想 · 口诀
动点问题不要慌，
定原点，建坐标，
速度时间写位置，
中点距离直接减，
动态变量全抵消，
绝对值里出双解！
📌 总结： 整体思想的核心是 “变中找不变”。通过代数表达将动态部分合并或抵消，从而剥离出固定关系。坐标法是最简洁的工具，分类讨论则帮助我们理解位置变化的全貌。

定原点，建坐标 ——把固定点A、C、B标上数字（0，a，4a）。

速度时间写位置——把文字描述的“动点”，变成了一个看得见、算得清的代数式，把动点M、D写成含 t 的代数式（如 4a−3vt）。

中点距离直接减——如果要求两个中点（比如P和Q）之间的距离，直接用中点坐标公式写出它们的坐标，然后拿大坐标减小坐标（取绝对值），不用管M跑到哪里，消去动态项M，得到不变量 PQ = a/2。

动态变量全抵消 ——只要涉及中点，动点的坐标在相减时必然抵消。

绝对值里出双解！ ——最后列方程 CM = 4PQ，因为距离带绝对值，自然解出两个答案。
